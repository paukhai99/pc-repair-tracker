# PC Repair Tracker

A Python terminal application for managing device repair tickets.

## Features

- Add repair tickets
- View saved tickets
- Update repair statuses
- Search by device name or problem
- Save tickets locally in a JSON file

## How to Run

With Python 3 installed, open a terminal in the project folder and run:

    python3 main.py

Follow the menu prompts.

## Data Storage

Repair tickets are saved in tickets.json.
This file is excluded from Git.
